* Intendants de données : _xyz (suppléant : abc)_
* Échéancier : _(p. ex. une date limite précise pour la publication ?)_
* Création de page
  * * [ ] (A.1) Créer la page principale du jeu de données
    * Utiliser [sections de la page du SGPD comme modèle](https://eccc-msc.github.io/open-data/msc-data/nwp_gdps/readme_gdps_fr/)
  * * [ ] (A.2) Ajouter un lien vers la page principale de ce jeu de données dans [la liste des jeux de données disponibles](https://eccc-msc.github.io/open-data/msc-data/readme_fr/)
* Contenu principal
  * * [ ] (B.1) Créer une sous-page pour le Datamart du SMC, si cela s'applique
  * * [ ] (B.2) Créer une sous-page GeoMet du SMC, si cela s'applique
  * * [ ] (B.3) Créer/mettre à jour le « tableau des variables » (communiquer avec @DupreX) 
  * * [ ] (B.4) Ajouter une carte Web avec l’empreinte du jeu de données ou créer et utiliser une image statique de l’étendue et de l’empreinte du jeu de données
* Contenu facultatif
  * * [ ] (C.1) Configurer une carte interactive propre au jeu de données, si pertinent
  * * [ ] (C.2) Mise à jour des [jeux de données par thème](https://eccc-msc.github.io/open-data/msc-data-themes/readme_fr/) si pertinent
  * * [ ] (C.3) Ajouter le diagramme de dépendance du modèle de PNT au moyen [d’un nouveau ticket chez CMDI](https://gitlab.science.gc.ca/CMDI/dependencyGraphs) (communiquer avec @archambaultb) , si cela s'applique
  * * [ ] (C.4) Ajouter des liens vers les documents techniques, tels que la version actuelle du système (si pertinent), dans la section « Documentation technique ».
* Validations
  * * [ ] (D.1) S’assurer que tout nouveau contenu est disponible en anglais et en français
  * * [ ] (D.2) Confirmer que les liens vers les métadonnées de découverte sur open.canada.ca et OMM WIS2 sont à jour (personne-ressource : @bruno.fang)
  * * [ ] (D.3) Validation finale du contenu par l’intendant des données
  * * [ ] (D.4) S’assurer que l'abstract du jeu de données correspond à celui des [métadonnées de découverte](https://gccode.ssc-spc.gc.ca/ec-msc/discovery-metadata/) (personne-ressource : @bruno.fang)
* Publication de la documentation
  * * [ ] (E.1) Publier la documentation
  * * [ ] (E.2) Annoncer la documentation nouvellement disponible
  * * [ ] (E.3) Une fois que tous les éléments de cette liste de contrôle sont marqués comme terminés, mettez à jour le [billet msc-open-data](https://gccode.ssc-spc.gc.ca/ec-msc/msc-open-data/-/issues) pour marquer la documentation publique comme terminée.
